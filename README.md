# ANF Presentation

Web-based presentation for Azure NetApp Files Tech Sharing session.

## Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS
- Motion (Framer Motion)

## Getting Started

```bash
npm install
npm run dev
```

## Controls

- `→` / `Space` / `PageDown` — Next slide
- `←` / `PageUp` — Previous slide
- `Home` / `End` — First / Last slide

## Build & Deploy

```bash
npm run build
```

Deployed to GitHub Pages via GitHub Actions.
